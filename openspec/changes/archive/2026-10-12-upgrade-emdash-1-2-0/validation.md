The repository already records an unresolved Local private-preview font issue; this run does not establish its root cause or repair it. Full preview appearance and real newsletter browser autosave remain unverified here and must pass the existing release checks before promotion.

Upload checks reported Local `/_emdash/api/auth/me` and `/_image` 404 diagnostics while their asserted behavior passed. They do not establish clean full-page network acceptance. Fixture editor checks are narrower than the real renderer.

An initial preview API run overlapped the publication test and failed its unchanged-state assertion. The serial rerun passed; documentation now requires sequential execution. Earlier editor fixture attempts hit a rebuilding asset/cold-render timeout, then exposed required-marker selectors matching an SVG; those selectors now target the marker span and both browsers pass.
