# Proposal

## Why

Release pages currently mention singles in prose but cannot present them or their clips as usable media. LOTUS has two published singles while its album is still upcoming.

## What Changes

- Let staff add ordered singles with listening links and ordered YouTube clips to any release, including upcoming releases.
- Show populated media below release details with a simple, responsive layout. Omit empty groups.
- Keep existing artist videos and the persistent player separate.

## Capabilities

### New Capabilities

- `release-media`: Author, validate, publish and render release-specific singles and clips.

### Modified Capabilities

None.

## Impact

Shared content schema, additive EmDash fields, Release editor, public release detail and preview renderer, and focused tests. No new dependency or commerce change. PRD code promotion and PRD content publication remain separate gates.
