# Streamline shared agent guidance

## Why

Agents repeatedly load unrelated instructions and reconstruct module ownership or settled decisions. The owner approved the shared harness/module plan on 2026-10-14.

## What Changes

- Route detailed guidance by task; retain all project constraints in their owners.
- Default UI implementation to Claude and non-UI to Codex, with explicit prompt-scoped overrides.
- Add selected module/feature guides and check their navigation.
- Preserve application behavior, configuration, publication boundaries and existing check runners.

## Impact

Agent documents and focused guidance tooling only. No product API, data migration, deployment, model or permission change. Existing user work remains in place.
