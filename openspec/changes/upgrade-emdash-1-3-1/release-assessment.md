# Release assessment, 19 October 2026

The interval from the current 1.2.0 pins contains 1.3.0 and 1.3.1. Core/admin/Cloudflare/auth/blocks changelogs and changed registry-client notes were reviewed against the custom Staff/API integration and published 1.3.1 packages. Current Node 24, Astro 7, React 19 and Wrangler satisfy the new packages' peer/engine requirements.

| Upstream change                                                              | BlackBox adoption                                                                                                                                              |
| ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Rich-text image replacement and touch scrolling                              | Inherit through PortableTextEditor; verify touch selection and replacement.                                                                                    |
| Unchanged editor opening and supported rich-text pastes                      | Inherit and verify no new draft on open; preserve unsupported-block rejection.                                                                                 |
| New text links no longer forced to a new tab                                 | Adopt; existing `blank: true` links remain unchanged.                                                                                                          |
| Image field caption preservation                                             | Add optional string caption only to strict native revision enrichment; retain empty values and legacy metadata without widening writes or backfilling records. |
| Native draft visibility and D1 createField correctness                       | Adopt upstream; retain BlackBox Access roles, private media and accepted publication.                                                                          |
| CLI Access headers, URL selection and token refresh                          | Useful for CLI operations; no change to custom Staff authentication.                                                                                           |
| Lock takeover                                                                | Document explicit operator recovery with candidate target/fingerprint; do not automate it.                                                                     |
| Native revision viewer and inline visual-editing controls                    | Defer. Staff uses PortableTextEditor, not ContentEditor; these add capability and do not replace BlackBox publication history/review.                          |
| AI-training robots policy and experimental D1 coalescing                     | Defer; public robots policy is separately owned and D1 ordering/performance needs its own measured change.                                                     |
| Native menus, comments, imports, registry features and translation additions | No additional integration; retain English-only native build and existing enabled surfaces.                                                                     |

Both patches remain required: upstream lacks atomic revision-fenced deletion, the missing-row save conflict and the scoped Staff upload/editor controls. Target and source contain the same 90 migration names through 091, but require distinct build manifests/fingerprints. Source provenance is retained in `.codex-artifacts/emdash-1.3.1/source-provenance.json`; migration names alone cannot distinguish 1.1.0 from 1.2.0.
